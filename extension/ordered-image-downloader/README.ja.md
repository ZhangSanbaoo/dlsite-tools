# 順番画像ダウンローダー（Chrome 拡張）

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

現在のページの画像を上から順にプレビューし、不要なものを外し、ドラッグで並べ替えてから、指定した名前のフォルダに `00, 01, …` と連番でダウンロードします。UI は Chrome の言語に従います（中 / 英 / 日）。

## インストール

Chrome ウェブストア（準備中）から、または手動で：
1. リリースの zip を固定の場所に展開。
2. `chrome://extensions` を開き、**デベロッパーモード** をオン。
3. **パッケージ化されていない拡張機能を読み込む** → `ordered-image-downloader` フォルダを選択。
4. パズルアイコンのメニューからピン留め。

Edge など他の Chromium 系ブラウザでも同様です。

## 使い方

1. 目的のページでツールバーのアイコンをクリック。遅延読み込み画像を表示させるため一度自動スクロールし、画像を 1 行 3 枚で一覧表示（既定で全選択）。
2. フォルダ名を入力（必須）。
3. 画像をクリックで選択／解除、ドラッグで並べ替え。バッジに最終的な番号がリアルタイム表示。
4. **ダウンロード開始**。進捗画面で各画像の状態（待機／ダウンロード中／成功／失敗）を表示。ポップアップを閉じてもバックグラウンドで続行。再度アイコンを押すと進捗に戻り、**選択に戻る** で調整できます。
5. 選択状態（走査結果・選択・順序・フォルダ名）はタブごとに保持され、再読み込み・遷移・閉じるまで残ります。**再走査** で破棄。
6. 失敗した画像は赤く表示され理由が出ます。**失敗した画像を再試行** で番号を変えずに再試行。

## 連番の規則

`00` から開始。桁数は選択枚数に必要な桁数で最低 2 桁：100 枚以下 → `00`〜`99`、101〜1000 枚 → `000`〜`999`、1001〜10000 枚 → `0000`〜`9999`。拡張子は元の形式を維持（jpg / png / webp / gif …）。URL に拡張子がない場合はファイルの中身から判定します。

## 保存先（設定で切り替え可能な 2 モード）

**ブラウザのダウンロード（既定）**
- Chrome のダウンロード API を使い、既定のダウンロード先の中にフォルダを作ります。デスクトップに置きたい場合は Chrome の既定ダウンロード先をデスクトップに変更してください。
- Chrome の「ダウンロード前に各ファイルの保存場所を確認する」はオフにしてください。
- IDM などのダウンロード拡張と併用すると IDM 側に無害な「ファイル名を付けられませんでした」表示が出ます。また本拡張を IDM より*後に*インストールする必要があります（下記の制限参照）。

**直接書き込み（任意）**
- 設定で「保存方法」を直接書き込みに切り替え、保存先を一度選びます。**Chrome ではデスクトップ・ドキュメント・ダウンロードそのものは選べません**（「システムファイルが含まれる」）。デスクトップにフォルダ（例：`画像`）を作ってそれを選んでください。
- 以後は入力した名前のフォルダをその中に作り、画像を直接書き込みます。ブラウザのダウンロード一覧を経由しないため IDM と干渉せず、通知も出ません。
- ブラウザ再起動後の最初のダウンロード時に「アクセスを許可」を一度押します。

## 設定（ポップアップの歯車）

- 小さい画像を除外（既定オン、100×100 未満）、しきい値変更可
- 重複を除外（既定オン）
- 走査前に自動スクロール（既定オン）
- CSS 背景画像も含める（既定オフ）
- 同時ダウンロード数（既定 3）
- 保存方法と直接書き込みの保存先

## 制限

- ブラウザ内部ページ（`chrome://`、ウェブストア）は走査できません。
- クロスオリジンの iframe 内の画像は収集しません。
- ブラウザのダウンロードモードで IDM と併用する場合、Chrome は*最後にインストールされた*拡張にファイル名を決めさせるため、本拡張を IDM の後にインストールする必要があります。IDM の再インストールで名前が崩れたら、本拡張を一度削除して読み込み直してください。
- 厳しい直リンク対策のサイトでは 3 段階の取得すべてが拒否されることがあり、その画像は失敗として表示されます。手動で保存してください。
