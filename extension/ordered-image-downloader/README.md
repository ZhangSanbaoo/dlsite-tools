# 顺序图片下载器（Chrome 扩展）

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

界面跟随 Chrome 的语言自动切换（中 / 英 / 日）。

按页面从上到下的顺序预览当前网页里的图片，取消不要的、拖拽调整顺序，然后批量下载到指定文件夹并自动编号。

## 安装

**推荐**：从 [Chrome 应用商店](https://chromewebstore.google.com/detail/nbmhpjbgahnfbabcflpcbkppnllbiihe) 一键安装（审核通过后生效）。

手动安装：
1. 从 [Release](https://github.com/ZhangSanbaoo/dlsite-tools/releases) 下载压缩包，解压到任意固定位置（不要删，Chrome 会直接从这个目录加载）。
2. 打开 Chrome，地址栏输入 `chrome://extensions` 回车。
3. 右上角打开「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择解压出来的 `ordered-image-downloader` 文件夹。
5. 点浏览器右上角的拼图图标，把「顺序图片下载器」固定到工具栏。

Edge 等 Chromium 内核浏览器安装方式相同（`edge://extensions`）。

## 使用

1. 打开想下载图片的网页，点击工具栏图标。
2. 插件会自动滚动一遍页面（触发懒加载）并列出所有图片，一行 3 张，可滚动查看。默认全部选中。
3. 在顶部输入文件夹名称（必填）。
4. 点击图片可取消/重新选中；按住图片拖动可以改变顺序。左上角的编号实时显示最终文件名。
5. 点「确定下载」。下载面板会逐张显示状态（等待 / 下载中 / 成功 / 失败）；下载在后台进行，关闭弹窗也不影响，再次点图标可回到进度，点「返回调整」可回到选图界面。
6. 选图状态（扫描结果、勾选、顺序、文件夹名）按标签页保存，直到该页面刷新、跳转或关闭；点「重新扫描」会丢弃当前状态重新扫。
7. 失败的图片会标红并显示原因，点「重试失败的图片」即可重试，编号保持不变。

## 编号规则

从 `00` 开始，位数由已选图片的数量决定，最少 2 位：
- 100 张以内 → `00` ~ `99`
- 101 ~ 1000 张 → `000` ~ `999`
- 1001 ~ 10000 张 → `0000` ~ `9999`

文件扩展名保持原始格式（jpg / png / webp / gif …）；URL 里没有扩展名的会根据服务器返回的类型自动补上。

## 保存位置（两种模式，设置里可切换）

**浏览器下载（默认）**
- 走 Chrome 的下载接口，存到 Chrome 默认下载目录的子文件夹。想直接出现在桌面：Chrome 设置 → 下载内容 → 位置 → 改为桌面。
- 请不要开启 Chrome 的「下载前询问每个文件的保存位置」。
- 与 IDM 共存时 IDM 卡片上会出现一条无害的命名冲突提示，且本插件需要装得比 IDM 晚才能正确命名（见下）。

**直接写入（可选）**
- 在设置页把保存方式切到「直接写入」，并选一次保存位置。**Chrome 不允许直接选「桌面」「文档」「下载」这几个文件夹本身**（会提示"包含系统文件"），请在桌面上新建一个文件夹（如「图片」）再选它。
- 之后每次下载都在这个位置里自动创建以你输入的名称命名的文件夹，把图片直接写进去；进度照常在弹窗里看，关掉弹窗也不影响。
- 完全不经过浏览器的下载列表，因此和 IDM 等下载工具互不干扰，不会再出现命名冲突的警告；Chrome 的"下载前询问保存位置"也不影响它。
- 每次重新打开浏览器后的第一次下载，点「开始下载」时 Chrome 会弹一个"允许访问「图片」文件夹"的确认，点允许即可（也可以在设置页点「允许访问」）。


## 设置（点弹窗右上角 ⚙）

- 按尺寸过滤小图片（默认开，100×100 以下排除），可自定义阈值
- 去重（默认开）
- 扫描前自动滚动页面（默认开）
- 同时抓取 CSS 背景图（默认关）
- 同时下载数量（默认 3）
- 保存方式：直接写入 / 浏览器下载，以及直接写入的保存位置

## 已知限制

- 浏览器内部页面（`chrome://`、应用商店等）无法扫描。
- 跨域 iframe 里的图片不会被收集。
- （仅「浏览器下载」模式）与 IDM 等下载扩展共存：Chrome 规定"最后安装的扩展"决定文件名，本插件需要装得比 IDM 晚才能正确命名。
  IDM 卡片上会出现"此扩展程序无法将下载的文件命名为…"的提示，这是正常现象，不影响 IDM 使用。
  如果以后重装/更新了 IDM 导致文件名又变回原名，把本插件移除后重新加载一次即可。
- 极少数网站对图片做了防盗链且三种下载方式都被拒绝时会标记失败，可在页面里右键另存。
