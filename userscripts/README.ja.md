## DLsite お気に入りを割引順に並べ替え

[Greasy Fork](https://greasyfork.org/ja/scripts/602350-dlsite) からインストール、または `dlsite-wishlist-sort.user.js` をブラウザで開く。

お気に入りページの並び替え欄の下に「割引順に並べ替え」バーを追加します。

- **有効化** で現在の絞り込み条件のままお気に入りの全ページを取得（1 ページ 100 件、4,000 件で約 40 リクエスト、初回は十数秒）し、作品情報 API で割引率・価格・終了日時を照合して、サイト標準のリストと置き換えます。結果は 15 分キャッシュ。**再取得** で強制更新。
- 並び順：割引率（同率なら割引後価格の安い順）／割引後価格／値引き額／定価。
- **割引** プルダウンには今回取得した割引率が並びます（例：`90% OFF（12）`）。選ぶとその割引率の作品だけ表示。
- 範囲：全ページ／このページのみ。表示：画像／リスト。結果はページ分割（30 / 50 / 100 件）。
- ローカル絞り込み：割引中のみ、キーワード（タイトル／サークル）。フォルダや分類などサイト標準の絞り込みはそのまま有効。
- **購入済みを非表示**（既定オン）はサイトの「購入済みを非表示」条件を付けて取得。非表示になった購入済み件数をステータスに表示。
- **購入済みを整理** は、全リストと未購入リストの差分から購入済みなのにお気に入りに残っている作品を見つけ、確認ダイアログの後に DLsite 自身の削除 API で削除します。**取得後に自動整理** は確認なしで自動実行（既定オフ、有効化時に再確認）。
- **カートに入れる** は、その作品が現在のページにあればサイト標準のボタンを押し、なければ DLsite のメソッドを呼び、それも無理なら作品ページを開きます。
- **終了** で標準リストに戻ります。有効状態は記憶されます。

## DLsite カート割引プラン

[Greasy Fork](https://greasyfork.org/ja/scripts/602351-dlsite) からインストール、または `dlsite-cart-optimizer.user.js` をブラウザで開く。

カート一覧の上に折りたたみ式の「カート割引プラン」パネルを追加します。

計算方法 — ルールはすべて DLsite のカートページのコード（`PaymentSummary` コンポーネントと `Bulkbuy` オブジェクト）そのままです：
- 1 回の会計で使えるクーポンは 1 枚。「何回でも利用可」のクーポンは複数回の会計で使い回せます。
- **「作品指定／サークル指定」のクーポンは 1 回の会計で最も高い対象作品 1 件にのみ適用** されます。そうした作品をまとめて買うと 1 件しか割引されないのはこのためで、別々の会計にするべきです。
- 複数作品向けクーポンは対象作品の合計に適用され、上限額・最低購入額・「N 作品以上」条件に従います。
- セット割は同じ会計内の対象作品数で判定され、すでに成立しているセットを崩すことはありません。
- 所持クーポンは `/mypage/coupon/list/ajax` から都度取得するため、クーポンが変わってもスクリプトの更新は不要です。

「最大 N 回に分割」の範囲で総額が最小になる分け方を局所探索で求め、「今のまま 1 回で会計」（DLsite の既定の提案）と比較します。

パネル：
- **最大 N 回に分割**（既定 8）。**「あとで買う」を含む** でそれらも計算に含めます。
- 各回の件数・小計・**会計時に選ぶクーポン**・セット割の状態・支払額を表示。開くと各作品のセット割／クーポンのタグが見られます。
- **この回だけ残す** で他の作品を「あとで買う」へ移動（元に戻せます。削除はしません）。会計後に戻って **すべてカートに戻す** を押すと残りで再計算。カートが空のときも同じボタンが出ます。
- 「もう少しでさらにお得」に、あと少しで条件を満たすセット割／複数作品クーポンを表示。
- 標準リストの各作品に小さなタグ：赤＝使えるクーポン（「単品」は最も高い 1 件のみ、「N件〜」は N 件必要）、紫＝セット割の状態。

注意：スクリプトはカートと「あとで買う」の間で移動するだけで、注文や削除は行いません。決済方法の最低金額やポイント利用は考慮しません。次の「購入内容の確認」ページで表示どおりのクーポンを選んでください。
