# DLsite 油猴脚本

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

两个脚本都需要 [Tampermonkey](https://www.tampermonkey.net/)。界面语言跟随 DLsite 页面语言（中 / 英 / 日）。

## DLsite 收藏夹按折扣排序

### 安装
1. 确认已安装 Tampermonkey。
2. 把 `dlsite-wishlist-sort.user.js` 拖进浏览器，或在 Tampermonkey 面板 →「实用工具」→ 从文件导入 → 选这个文件，点「安装」。
3. 打开 DLsite 收藏夹页面，原生"排序"栏下面会多出一条「按折扣排序」工具栏。

### 使用
- 点「启用」：抓取当前筛选条件下的所有分页（每页 100 条，4000 件约 40 次请求，首次十几秒），再按 RJ 号批量查询 DLsite 商品信息接口校正折扣率 / 价格 / 截止时间，然后替换原生列表显示。
- 结果缓存 15 分钟，刷新页面、切换排序都不用重新抓；点「刷新数据」强制重新抓取。
- 排序：折扣力度（同折扣按折后价低→高）/ 折后价 / 节省金额 / 原价。
- 范围：全部分页 / 仅当前页（不抓分页，瞬间完成）。
- 显示：图片（卡片网格）/ 列表（横向行）。
- 「只看打折中」「筛选标题 / 社团」是在抓到的结果里做的本地筛选，和网站自带的筛选可以叠加。
- 网站自带的筛选（打折中 / 分类 / 隐藏已购买 / 收藏夹文件夹）会原样生效：脚本抓的就是当前 URL 对应的列表。
- 「退出排序」恢复网站原生列表。启用状态会记住，下次打开收藏夹自动进入排序模式。

### 已购买的收藏
- 「隐藏已购买」开关（默认开）：抓取时带上 DLsite 自己的"隐藏已购买"条件，状态栏会显示"另有 N 件已购买未显示"。
- 「清理已购买」按钮：对比"全部收藏"和"未购买收藏"两份列表，找出已购买却还在收藏夹里的作品，弹窗确认后逐个取消收藏（用的是 DLsite 自己的删除接口）。
- 「抓取后自动清理」：勾选后每次抓取完成自动执行，不再弹确认。默认关闭，开启时会二次确认。

### 注意
- 「加入购物车」会在新标签页打开 DLsite 的加购页面，加完可以直接关掉。
- 如果某天 DLsite 改了页面结构导致"无法解析列表"，把新页面的 HTML 发我即可更新脚本。


## DLsite 购物车优惠方案

打开 DLsite 购物车页面，脚本会在商品列表上方给出一份"怎么分单、每单用哪张券"的方案，并在每件作品下方标出它能用的券和组合特价状态。

### 安装
把 `dlsite-cart-optimizer.user.js` 拖进浏览器，Tampermonkey 会提示安装。

### 它怎么算
计算规则全部照搬自 DLsite 购物车页面自己的代码（`PaymentSummary` 组件和 `Bulkbuy` 对象），不是猜的：
- 每单只能用一张券；"不限使用次数"的券可以在多单重复使用。
- **指定作品 / 指定社团类的券一单只对价格最高的一件生效**——这就是"几件一起买只打一件折"的原因，这类作品应各自单独结账。
- 多件券按对象作品合计打折，受封顶金额、满额、"N 件起"等条件约束。
- 自选组合特价按同一单内的对象作品件数自动套用，拆单时会保证不破坏已满足的组合。
- 持有的券实时从 `/mypage/coupon/list/ajax` 读取，所以券变了不用改脚本。

脚本用局部搜索在"最多拆 N 单"的限制内找总价最低的分法，并和"现在一次结账"（DLsite 默认推荐的那张券）对比显示能省多少。

### 面板说明
- **最多拆成 N 单**：限制单数，默认 8；单数越多越可能更省，但结账更麻烦。
- **含稍后再买**：把「稍后再买」里的作品也纳入计算。
- **只保留这一单**：把其它单的作品移到「稍后再买」（不删除，可逆），购物车里只留这一单，然后你正常去结账。结账时在"确认购买内容"页按面板标注选对应的券。
- **全部放回购物车**：结完一单回到购物车，点它把「稍后再买」的作品全部放回，面板会对剩下的作品重新计算，继续下一单。
- **再加一点就能更省**：提示哪些组合特价 / 多件券差几件就能触发。
- 每件作品下方的小标签：红色＝可用的券（"·单件"表示一单只对最贵一件生效，"·N件起"表示需要凑件数），紫色＝组合特价状态。

### 注意
- 脚本只移动"购物车 ⇄ 稍后再买"，不会下单、不会删除作品。
- 不考虑支付方式的最低金额限制（如 Edy 需 330 円以上）和点数抵扣。
- 如果 DLsite 改了页面结构或计算规则，面板会报错或结果与实际不符，届时把购物车页面发我更新。
